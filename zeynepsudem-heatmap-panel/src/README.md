# Campus Heatmap (Zeynep Sudem)

Building × time heatmap. Each row is a series, each column a time bucket, the colour is the average value.

- Click a cell to zoom the dashboard to that time bucket
- Click a building name to set the `building` dashboard variable (drill-down)
- Colour schemes (heat, cool, diverging), automatic or fixed number of columns, values in cells

Developed by Zeynep Sudem for MIS 233 Advanced Web Development, Boğaziçi University, Fall 2026.
