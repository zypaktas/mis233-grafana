# Insight panel (Zeynep Sudem)

Time series panel with **in-browser AI**: a small neural network is trained on the panel's own data
to forecast the next points (with a 95 % band) and to flag anomalies, and the result is explained in plain language.

- Display modes: line, area, points · colour · line width · grid · stats strip · threshold highlight
- Hover tooltip, click to pin a point, drag to zoom, click the legend to hide a series
- Responsive: compact layout for small panels, sliding window for live (streaming) data
- AI options: on/off, forecast horizon, anomaly threshold (σ), summary, which series to analyse

Developed by Zeynep Sudem for MIS 233 Advanced Web Development, Boğaziçi University, Fall 2026.
